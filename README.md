# رحّال لنقل البضائع

موقع تعريفي لشركة نقل بضائع في المغرب، باللغة العربية واتجاه RTL.

## البنية

```
index.html   الصفحة الرئيسية
404.html     صفحة الخطأ
style.css    التنسيقات
main.js      التفاعلات: القائمة، الخريطة، النموذج، التتبّع
favicon.svg  أيقونة الموقع
robots.txt
```

موقع ثابت لا يحتاج أي بناء أو مكتبات. يكفي رفع الملفات إلى أي استضافة.

## قبل النشر

عدّل البيانات التالية في `index.html`: رقم الهاتف `+212 522 00 00 00`، رقم واتساب في الرابط `wa.me/212600000000`، البريد `contact@rahhal.ma`، والعناوين.

نموذج طلب السعر يعرض رسالة تأكيد فقط ولا يرسل البيانات. لاستقبال الطلبات فعليًا اربطه بخدمة مثل Formspree أو Netlify Forms أو بواجهة خلفية خاصة بك.

الصور والفيديو مستضافة على خوادم Higgsfield. يُفضَّل تنزيلها ووضعها في مجلد مجلد `media/` ثم تحديث الروابط في `index.html` و`style.css`.
